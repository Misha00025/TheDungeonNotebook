# Commit Convention

Коммиты — по завершённым фазам изменений, с префиксом:
- `feat:` - для нового функционала или заметного изменения
- `fix:` - для исправления бага, починки поведения
- `refactor:` - для чистки кода, переименовывания или перекладывания файлов без явного влияния на поведение
- `chore:` - для незначительных изменений

Если количество изменений на фазу мало, а фаз много - можно объединить их в группы и коммитить группами.

Перед каждым коммитом:
- `dotnet build && dotnet test` в затронутом C# сервисе
- `./test.sh 15` в `backend/api-gateway/tests/` для сквозных тестов

Финальный прогон сквозных тестов — после завершения всех фаз.
