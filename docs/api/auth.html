🔐 Аутентификация

Входящие Bearer access tokens проверяются через Gateway и Account service. Старые браузерные auth-маршруты намеренно возвращают 410; они не являются API для входа.

Клиент передаёт Bearer-токен Gateway. Gateway вызывает внутренний POST /internal/auth/validate Account service с отдельным confidential caller key; этот внутренний endpoint не предназначен для браузеров. Поддерживаются настроенные JWT access tokens, а не opaque tokens. Регистрация, выдача и обновление токенов через старые маршруты здесь не реализованы.
