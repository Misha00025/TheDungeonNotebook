# История объединения репозиториев

Web был локально объединён с The Dungeon Notebook через Git subtree без squash. Исходные commit hashes не переписывались; старые Web-коммиты до импорта сохраняют прежние корневые пути.

Ветки-архивы исходных ссылок сохранены под `archive/web/local/*` и `archive/web/origin/*`; tip импорта — `archive/web/import-main`. Теги Web находятся под `web/*`. Существующий тег TDN `0.1.0` оставлен без изменений.

Из-за смены префикса обычный просмотр истории по текущему префиксу может не показывать всю раннюю историю Web. Для неё используйте Git ref импорта:

```bash
git log archive/web/import-main
```
