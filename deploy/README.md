# Терминальное меню развёртывания

Меню управляет существующими установками Backend+BFF, Web и Keycloak: показывает состояние сервисов, выполняет update, restart и stop. Установка с нуля пока не поддерживается. Отсутствующие установки не скрываются и не создаются автоматически.

Скачайте меню и запустите его:

```sh
curl -fsSLo menu.sh https://raw.githubusercontent.com/Misha00025/TheDungeonNotebook/master/deploy/menu.sh
bash menu.sh
```

Ручной clone репозитория не требуется. Главное меню содержит три пункта: управление конфигурацией, управление сервисами и выход. В конфигурации задаются только пути установки; отдельное действие «Обновить menu.sh» скачивает и проверяет новую версию по подтверждению пользователя. Стрелки и Enter выбирают действия; Tab/Shift+Tab перемещают фокус в форме, Esc возвращает назад, PgUp/PgDn и ←/→ прокручивают длинный вывод.

Требуются Bash 4.3+, coreutils, stty, tput, awk, sed, curl; для действий с сервисами — Docker Compose v2; для update — Git, Make и setsid (util-linux). Пакеты автоматически не устанавливаются. Конфигурация меню хранится рядом с файлом как `.tdn-menu.conf`.

Действие «Обновить» получает исходники в отдельный кэш `${XDG_CACHE_HOME:-$HOME/.cache}/tdn-menu/sources`, затем собирает соответствующие образы и только после успешной сборки пересоздаёт выбранные application services. «Перезапустить сервисы» перезапускает только выбранные сервисы; «Выключить сервисы» останавливает только выбранные сервисы. Перезапуск и выключение не скачивают исходники и не собирают образы. Все действия сохраняют файлы установки и данные.

Меню не меняет Compose-файлы и `.env`. Обновление рассчитано на известные имена application services; другие сервисы не переименовываются и не обновляются. Keycloak обновляет образ только для тега, уже указанного в Compose. При изменении upstream Compose-определений их нужно обновить отдельно. Изменения локального checkout исходников блокируют обновление, чтобы не затереть работу.
