# Интеграционные тесты API Gateway

Команды выполняются из каталога, в котором находится этот README.

```bash
./test.sh 15
./test.sh 15 -S GatewayMain
./test.sh 15 -S GatewayMain -S UserProfile
./test.sh 15 -c
./test.sh 15 -d
./test-ci.sh
./test-ci.sh -S GatewayMain
```

Первый аргумент `test.sh` — дополнительное ожидание в секундах; следующие аргументы передаются тестовой команде. Фильтр `-S` можно повторять. `-c` включает компактный вывод, `-d` — отладочный. CI-скрипт принимает фильтры и другие аргументы тестовой команды.

**Внимание:** запуск очищает тестовые данные баз данных, пересоздаёт сертификаты и управляет тестовыми контейнерами. CI-скрипт также останавливает и удаляет ресурсы Docker Compose. Запускать только в предназначенном для тестов окружении.

Корневая команда `make test` также запускает интеграционные тесты и очищает тестовые данные перед запуском.
