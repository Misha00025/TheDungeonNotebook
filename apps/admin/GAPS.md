# Исторические гипотезы и предложения

Ниже сохранены предложения из прежней заметки. Они не описывают актуальную архитектуру или проверенное отсутствие возможностей и требуют сверки с кодом и публичной HTML-документацией.

## Предложение: смена пароля пользователя

В прежней заметке предлагался endpoint `POST /auth/password-change`, принимающий `userId` и `newPassword`, для административного сброса или смены пароля.

## Предложение: получение username по user ID

В прежней заметке предлагался endpoint `GET /auth/users/{id}` с ответом, содержащим `id` и `username`. В качестве пакетного варианта указывался `GET /auth/users?ids=1,2,3` с коллекцией пользователей.
